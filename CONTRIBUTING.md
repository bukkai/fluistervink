# Bijdragen aan Fluistervink

Fijn dat je wilt helpen. Zo werkt het:

## Feedback en ideeën: graag

- **In de app:** zeg tijdens een sessie "feedback, …" of typ het op het scherm Feedback. Dat komt bij de ontwikkelaar terecht als je delen hebt aangezet.
- **Op GitHub:** open een issue met wat je zag, wat je verwachtte en (als je het weet) welke versie van de app het was.

Fouten, wensen, verkeerd verstane vogelnamen, onduidelijke teksten: alles is welkom.

## Code: geen pull requests

Pull requests met code worden niet gemerged. Dat is niets persoonlijks: de eigenaar wil alle code zelf kunnen blijven gebruiken, ook onder andere voorwaarden dan de AGPL (dubbele licentie). Dat kan alleen als hij de enige auteur is.

Heb je een verbetering gemaakt? Open dan een issue en beschrijf wat het doet en waarom. Een link naar je fork mag erbij. Als het idee past, bouwt de eigenaar het zelf opnieuw, zonder jouw code over te nemen.

Natuurlijk mag je onder de AGPL je eigen fork maken en verspreiden (zie [LICENSE](LICENSE)).

---

## Contributing (English)

Feedback and ideas are welcome, in the app or as a GitHub issue. Pull requests with code are not merged: the owner wants to remain the sole author so the code can also be used under other terms than the AGPL (dual licensing). Describe your improvement in an issue instead, optionally with a link to your fork; if it fits, the owner will build it from scratch without copying your code. You are of course free to fork under the AGPL.
